# Mend On The Go (Fabric, Minecraft 26.3)

Port of the MCreator NeoForge 26.1.2 mod. Hold the **Mend** key (default Left Shift) or toggle `/repair`:
each tick the Mending item in your main hand regains 2 durability for 1 XP point.

Build (needs JDK 25): `./gradlew build` -> `build/libs/mend_on_the_go-1.0.0.jar`
Requires Fabric Loader >= 0.19.5 and Fabric API for 26.3. Must be installed on the server and client.
